# Changelog

## 1.0.0

- First release: nested explanation windows (DeepTip specification 1.0) for Valheim.
- Valheim's tooltips become DeepTip windows: beside their element, enterable, with highlighted terms.
- Valheim glossary in English and German, help entries for DeepTip itself.
- Lexicon page in the Compendium, searchable.
- Automatic highlighting of known terms in tooltips of Valheim and other mods.
- Glossary files from any mod's `deeptip` folder, user overrides in `BepInEx/config/DeepTip`, and a C# API.
